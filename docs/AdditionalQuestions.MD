Licenses, certifications & clearances (structured)
Each of these is really a cluster of sub-fields, which is why they're worth their own handling:
•	Professional license: number + issuing state + expiration [text × 3, sensitive]
•	Security clearance: level (Confidential/Secret/TS/TS-SCI) + status (active/current/none) + granting agency [enum + enum + text, sensitive]
•	Driver's license: number + class + state + endorsements [text, sensitive]
•	Certifications: name + issue date + expiry [repeating]
•	Domain IDs: FINRA CRD, NPI, DEA, bar number + jurisdiction [text, sensitive]
